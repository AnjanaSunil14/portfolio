About

I'm a final-year MCA student at MACFAST College, Thiruvalla, building toward a career as a software engineer who ships things that work — not just things that compile.

Projects

Things I've built end to end

Team Project — BCA, 2nd Year

Driver Hiring Platform

Hire a driver, not a ride — a booking platform for people who already own a car.

Problem

Existing ride-hailing apps bundle a vehicle with every driver, which is useless to someone who just needs a driver for their own car.

Solution

A three-role platform — Admin, Driver, and User — that separates driver hiring from vehicle rental entirely, with real-time booking, feedback, and role-based access.

My Contributions

  • Engineered the User and Driver dashboards in HTML, CSS, and JavaScript.
  • Designed and built the booking and feedback REST APIs in Django.
  • Implemented authentication and role-based access control across all three roles.

Team Project — BCA, Final Year

Legal Hub

Replacing paper case files with a secure system advocates can actually search.

Problem

Advocates in India still manage cases with paper records and CDs — nothing is searchable, backed up, or accessible remotely.

Solution

A role-based case management platform for Admins, Advocates, Entry Staff, Users, and the Public — with encrypted case storage, live status updates, and in-app chat.

My Contributions

  • Owned the Admin module end to end — frontend and backend — covering advocate registration and case-type management.
  • Built backend logic in PHP against MySQL, implementing CRUD operations and role-based access across five user roles.
  • Collaborated with a 3-person team to ship encrypted case-file storage and real-time status tracking.
